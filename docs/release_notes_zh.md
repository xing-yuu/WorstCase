# 修改与验证说明

本项目已按确认方案修改。原始 ZIP、论文和问题报告未被覆盖。
公开代码位于本目录上一级；运行说明见 [README](../README.md)。
当前源码可供审阅和测试。选定的摇椅、飞机、修正后叶片主算法完整运行均已
退出码 0 完成；其中摇椅和飞机使用修正前冻结程序，叶片使用边界修正后的
冻结程序，因此不能称为同一最终代码版本的完整三模型验证。重网格边界修正
和求解报错改进已通过 Windows 核心/可选构建、WSL 回归测试。代码并非
与稿件逐字一致，也不作“无 bug”或全面发布验证已完成的保证。

材料口径已按用户最终决定从 E=1、nu=0.3 改为直接使用 Lamé 参数
lambda=1、mu=0.3。配置键为 `lame_lambda`、`lame_mu`；本构矩阵、调用接口、
单轴解析测试、回归基准和下列验证数据均已更新。旧材料完整实验仅作历史记录，
不用于证明本版本的三模型优化效果。

## 已落实的关键数值口径

| 项目 | 实现 |
|---|---|
| 材料 | 按论文约定使用 Lamé 参数 lambda=1、mu=0.3 |
| 刚体零空间惩罚 | 保留 1e7 × 当前 K 的最大特征值 |
| 特征求解容差 | 1e-10 |
| Inner problem | 三个最小特征对，逐个求位移后选柔度最大的候选 |
| 线性求解器 | 投影 AMG-CG 与投影 AMG-GCR；config 的 `linear_solver` 选择，默认 GCR |
| E_ss 求和范围 | **仅含至少一个边界面的四面体**；仅接触边界顶点或边的单元不算 |
| 应力诊断 | 最大绝对主应力；分别记录边界单元和全部单元，另列 sigma_bar |
| Phase I | E_ss + E_si + E_ef，默认单位权重 |
| Phase II | 固定 sigma_star，包含 E_ss，并联合优化形状与局部二面角平滑 |
| 其他参数 | gamma=.5；d0=d1=d2=.001；epsilon_d=.0001；1000×5 次迭代上限 |

E_ss 的标量上界求解、能量与直接应力导数使用同一边界集合；
平衡方程和刚度矩阵导数仍使用全部四面体。
所有 Sec.2 决策以及质量公式、eta 调整、采样权重等细节见
[implementation_notes.md](implementation_notes.md)。

保留的明确稿件差异包括：稿件以初始刚度最大特征值规定零空间惩罚，当前代码
使用每轮当前刚度的最大特征值再乘 1e7；稿件描述单个最小特征对，当前代码
计算三个最小候选并选柔度最大者；特征求解使用 Spectra 而非稿件所述 ARPACK；
网格改善仍使用 MMG，而非稿件引用的 Jiang 方法。此前确认保留这些选择，
不等于稿件原文已与实现相同。Lamé 材料参数现已按稿件约定统一。

## 项目改动

- 将 FEM、最坏载荷分析、五个能量项、两阶段优化、网格读写和重网格化拆成独立模块。
- 修复报告中重复/错权重梯度、自交梯度丢失、平滑值与梯度不一致、
  随机线搜索、共享变量竞争、内存泄漏、缺失返回等问题。
- 统一能量值和梯度的实现；加入解析 FEM/伴随导数和有限差分验证。
- 增加坐标归一化、严格 JSON 配置、CLI、CSV 日志、原坐标输出、检查点续跑。
- 移除核心中的 CGAL、CppAD、LibShell、私改 AMGCL 头文件及本机绝对路径。
- 改用固定版本 CMake 依赖；隔离 IPC、MMG、fTetWild；统一英文源码与格式。
- 补充 MPL-2.0、引用信息、依赖许可证、可再生成的小模型、
  参数文档、实验统计/画图脚本和 CI。

表面输入的 fTetWild 依赖 Geogram，二者包含额外随机来源。
本实现关闭输入面随机打乱，并为固定版本 Geogram 的 shuffle 加入确定性补丁，
保留原许可证。单线程、独立进程重复生成体网格已验证逐字节一致。

## 构建与发布说明

MMG 使用保守策略：锁定边界，只有边界不变且质量提高才接受，否则回滚。
