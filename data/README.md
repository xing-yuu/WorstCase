# Example data

`beam.mesh` and `beam.obj` are original procedural examples generated by
`scripts/generate_example.py`. The volume mesh has 80 vertices and 216 linear
tetrahedra in a 1 x 0.3 x 0.2 box. The OBJ contains only its boundary vertices.

These example assets are distributed under the repository's MIT license.
They do not contain third-party models. Regenerate both with:

```sh
python scripts/generate_example.py
```

Paper benchmark assets are not redistributed in this package. Supply your own
authorized files to `scripts/run_benchmarks.py`.
